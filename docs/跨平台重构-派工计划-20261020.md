## 阶段一：建层（串行，1.5-2 天）

### P1-1 · 接口骨架 + win32 实现 + 参数化单测

**一句话**：新建 `engine/platform/`，定义十组接口，实现 win32，并让单测能用参数注入验三平台分支。

**交付物**
- `engine/platform/index.mjs` — 按 `process.platform` 选实现，导出 `platform` 与 `createPlatform(name)`（后者供测试注入）
- `engine/platform/win32.mjs` — 十组接口的 Windows 实现
- `engine/platform/darwin.mjs` / `linux.mjs` — 先给**完整签名 + 明确抛"未实现"**的骨架，不写假实现
- `tests/unit-platform.mjs` — 用 `createPlatform("win32")` 断言；加进 `tests/run-tests.mjs`

**边界**
- **只新增文件，不改任何现有文件**（`git diff --stat` 里只能出现新增）
- `index.mjs` 的 `platform` 导出必须与 `process.platform` 一致
- `spawnOpts` 与 `killTree` **必须写在同一个文件里、相邻位置**（方案 §3.3 原则一）
- `capabilities` 必须是对象，键固定为 `pkgManager` / `proxyControl` / `reveal`

**验收**
```powershell
node tests/unit-platform.mjs            # 全过
node tests/run-tests.mjs                # 22/22（新增 1 个套件）
git diff --stat HEAD                    # 只有新增文件，无 M
grep -rn "process.platform" engine/ --include=*.mjs   # 只允许出现在 platform/ 目录内
```

### P1-2 · darwin + linux 实现

**一句话**：把两个骨架填成真实现，靠参数注入单测验证，不需要真机。

**交付物**
- `engine/platform/darwin.mjs` — `which`(`which`)、`reveal`(`open -R`)、`readSystemProxy`(`scutil --proxy`，plist 文本解析)、`isRunning`(`pgrep`)、`homeDir`(`os.homedir()`)、`tempDir`(`TMPDIR`)、`killTree`(`process.kill(-pid)`)
- `engine/platform/linux.mjs` — 同上，`readSystemProxy` 走 `gsettings get org.gnome.system.proxy` + 环境变量回退，`reveal` 走 `xdg-open $(dirname)`
- `tests/unit-platform.mjs` 扩充：同一套断言跑三份实例

**边界**
- `capabilities` 的探测必须来自**真实调用**（`brew --version` / `apt --version`），不能靠"路径上有文件"推断（项目铁律）
- `readSystemProxy` 拿不到时返回 `{enabled:false, server:"", source:"none"}`，不抛
- `scutil` 的 plist 输出要能容忍三种形态：有代理、无代理、命令不存在

**验收**
```powershell
node tests/unit-platform.mjs            # 三份实例全过
node tests/run-tests.mjs                # 22/22
```
**注意**：darwin/linux 的实现只能在 Windows 上靠参数注入验逻辑，**真机行为未验证**，交付时要写明这一点。

## 阶段二：收编（串行，2-3 天）

前置：P1-2 通过。

### P2-1 · 收编 `engine/server.js`（4 处）

**一句话**：把 `explorer.exe` 换成 `platform.reveal`，修掉那个会让引擎进程直接退出的缺陷。

**为什么先做它**：最简单，且它包含全仓唯一一个"点一下就让引擎消失"的缺陷（`server.js:484` 的 `spawn` 无 error 监听）。

**边界**
- 只改这 4 处，不顺手改别的
- `reveal` 失败不能抛，要返回 `{ok:false, error}` 让上层回 500
- 保持 HTTP 响应形状不变

**验收**
```powershell
node tests/run-tests.mjs                # 22/22
# 新增一条：reveal 在 platform 抛错时，接口回 500 而不是进程退出
```

### P2-2 · 收编 `engine/dlcore.js`（21 处）

**一句话**：把 `taskkill` / `which` / `TEMP` / 路径处理收进 platform，同时补上 `detached`。

**这是最关键的一单**，因为它包含 `spawnOpts` 与 `killTree` 的配对修复。

**边界**
- `spawn(cmdBin, ...)` 改用 `platform.spawnOpts({...})`，确保 posix 下带 `detached`
- `process.kill(-pid)` 改用 `platform.killTree`
- **不许顺手改业务逻辑**：进度计算、状态机、节流参数一律不动
- 改完后必须验证「取消能杀掉整个进程树」**和**「引擎崩溃后命令型子进程不会变成孤儿」两件事

**验收**
```powershell
node tests/run-tests.mjs                # 22/22
# 新增两条用例：
#   ① 取消后，git 拉起的子进程确实消失
#   ② 引擎异常退出后，命令型子进程被清理（不残留孤儿）
```

### P2-3 · 收编 `engine/backends/aria2.js`（25 处）

**一句话**：候选路径表、`which`、大小写处理收进 platform。

**边界**
- 候选路径表本身保留在 aria2.js（它是 aria2 特有的，不是平台通用的），但**探测手段**换成 `platform.which`
- `resolveAria2Bin` 的 `opts.candidates` 注入参数保留（测试在用）
- 不动 `identifyOccupant`、RPC、实例管理

**验收**
```powershell
node tests/run-tests.mjs                # 22/22
# unit-aria2 133 项、unit-aria2-cache 28 项必须全过
```

## 阶段三：功能裁剪（可并行，1-2 天）

前置：P2 全部通过。

### P3-1 · `proxy-control` 在非 Windows 关闭
`capabilities.proxyControl = false`；UI 上这块入口**消失**（不是灰掉）；引擎侧调用直接返回 `{ok:false, error:"当前平台不支持代理控制"}`。
**验收**：Windows 行为完全不变；单测断言非 Windows 下返回明确的 unsupported。

### P3-2 · `winget` kind 在非 Windows 不注册
`capabilities.pkgManager === null` 时，`download-command` 的 `kind: "winget"` 直接拒绝并给出「当前平台可用的是 git / pip」。
**验收**：Windows 不变；非 Windows 下任务创建即失败，错误文案说清可用选项。

### P3-3 · `pip`/`uv` 的 PEP 668
探测 `externally-managed` 标记，命中时给出「请用 venv」的明确提示，**不要**用 `--break-system-packages` 糊。
**验收**：三平台单测（用 fixture 模拟 externally-managed 标记）。

## 派工纪律（每单都适用）

1. **任务书必写"用 codemode 批量执行"**
2. **`access="write"`，禁止传 `read`**
3. 边界写清「不要改 X」，比「只能改 Z」有效
4. 交付必须含：改动清单、证据（命令与输出）、未决项、回滚方式
5. 主脑验收通过才进下一单；不合格打回，主脑不替改
6. 每单完成后跑三平台 CI，**红了不进下一单**

## 回滚方式

| 阶段 | 回滚 |
|---|---|
| 单步 | `git revert <sha>` |
| 整阶段 | `git reset --hard <阶段起点 sha>` |
| 整体 | 分支删除，main 未受影响 |

**main 的安全性由"全程只在分支上操作"保证。** 任何一单搞砸，main 上跑的仍是 `ee5d594` 那套三平台全绿的版本。

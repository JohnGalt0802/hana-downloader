## 一、范围（严格遵守）

- **只改 `ui/card.js` 一个文件。**
- 不动 `ui/manager.js`、不动 `index.js`、不动 `manifest.json`。
- **不新增任何常驻 `setInterval` / `setTimeout` 轮询**；不改动既有轮询节奏
  （`FAST_MS=300` / `IDLE_MS=5000` 保持原样）。
- 既有全部 `reportSize()` 调用点（无参 / force 两种）行为保持兼容。

## 二、目标

切会话回来（含 iframe 重建、隐藏再显示两种路径）后，卡片能在**秒级**内把真实尺寸
（宽 400、高=内容高）重新报给宿主，宿主收窄回小卡形态；**尺寸已经正确时，一次多余上报都不发**。

## 三、改动点（四点，均为加法）

### 3.1 去重键纳入「宿主是否已采纳宽度」（治本）

现状（`ui/card.js` ~L61-73）：
```js
function reportSize(force) {
  const h = measureH();
  if (!force && h === lastReportedH) return;   // 只看高度
  ...
}
```
改为：非 force 时，**除高度外，若「宽度探查窗口」开着且宿主采纳宽度不达标，也照发**。
引入模块级时间戳 `widthProbeUntil = 0`：
```js
function reportSize(force) {
  const h = measureH();
  const widthOk = Math.abs(window.innerWidth - CARD_WIDTH) <= 2;
  const probing = Date.now() < widthProbeUntil && !widthOk;
  if (!force && h === lastReportedH && !probing) return;
  ...
}
```
> 语义：不在探查窗内时，行为与现在**完全一致**（按高度去重，零额外开销）；
> 探查窗内且宽度不对时，才允许发——且在宿主采纳后自动回到零开销。

### 3.2 宽度探查窗口的开启时机（有限窗口，不永久纠缠）

在以下两处把 `widthProbeUntil = Date.now() + 12000`（12 秒窗口）：
1. `bootSettle` 启动时（脚本加载 / iframe 重建时重跑）
2. 新增的 re-show 触发点（见 3.3）

窗口上限 12s：即便宿主始终不采纳，最多 12s 后自动恢复零开销，不会无休止重试。

### 3.3 re-show 强制补报（覆盖「隐藏再显示」路径）

新增（**纯事件监听，零轮询**）：
```js
function onReshow() {
  try {
    if (document.visibilityState && document.visibilityState !== "visible") return;
    widthProbeUntil = Date.now() + 12000;
    [0, 400, 1500].forEach((d) => setTimeout(() => reportSize(true), d));
  } catch { /* 事件不可用不影响主流程 */ }
}
document.addEventListener("visibilitychange", onReshow);
window.addEventListener("pageshow", onReshow);
```
> 三个 setTimeout 是一次性的，不是轮询；只在可见性变化时触发。

### 3.4 修 `adopted()` 提前收兵（去掉宽度单一判据）

现状（~L85-86、95）：
```js
const adopted = () => Math.abs(window.innerWidth - CARD_WIDTH) <= 2;
... if (adopted()) { clearInterval(timer); return; }
```
问题：宽度恰好≈400 时立刻收兵，**哪怕这次上报被宿主丢弃**。
改法（择一，执行者说明理由）：
- **方案甲（推荐）**：`adopted()` 保留但收兵条件改为「宽度达标」**且**本轮 `reportSize(true)` 已发出
  至少一次（即不在首帧就收兵）；或
- **方案乙**：删掉提前 `clearInterval`，让 `bootSettle` 跑满 6 次上限
  （6×1.5s，属既有行为，**不新增轮询**）。

两案都不得新增常驻定时器。
